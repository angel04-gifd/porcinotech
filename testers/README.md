## 🚀 Cómo participar

1. **Acepta la invitación** como colaborador que te llegó por correo o en [github.com/notifications](https://github.com/notifications).
2. **Instala la app:** descarga `PorcinoTech.apk` desde [Releases](../../../releases/latest) y ábrelo en tu Android.
3. **Pruébala** creando una cuenta, una granja (o uniéndote con un código) y recorriendo cerdos, corrales, alimentos y partos.
4. **Deja tus comentarios en tu archivo:** ábrelo desde la tabla de arriba, pulsa el lápiz ✏️, escribe y baja a **Commit changes**.
5. Si prefieres reportar algo puntual (sobre todo errores), usa el [formulario de observaciones](../../../issues/new?template=observacion.yml).

## ✅ Qué conviene probar

- Registro, inicio de sesión y recuperar contraseña con el código del correo.
- Crear una granja, cambiar entre granjas y unirse con un código de operador.
- Registrar cerdos, corrales, alimentos y consumos.
- Inseminaciones, próximos partos y partos reales.
- Qué puede y qué no puede hacer cada rol (administrador / operador).

## 📌 Reglas rápidas

- 🔓 El repositorio es **público**: todo lo que escribas aquí lo puede ver cualquiera. No pongas contraseñas, correos ni datos reales de granjas.
- ✏️ **Edita solo tu archivo.** No cambies el código ni los archivos de otros testers.
- 🗒️ Una fila por observación, y si es un error, explica los pasos para repetirlo.
